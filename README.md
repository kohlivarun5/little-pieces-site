# Little Pieces website

Public product, privacy and support pages for Little Pieces, by Varun Kohli.

- Home: https://kohlivarun5.github.io/little-pieces-site/
- Privacy: https://kohlivarun5.github.io/little-pieces-site/privacy/
- Support: https://kohlivarun5.github.io/little-pieces-site/support/
- Email: kohli.varun5@gmail.com

Plain HTML and CSS, with local light/dark icon assets. No JavaScript, analytics,
third-party fonts, contact forms, or build dependencies. The current app version
is free to play with unlimited photo imports; this site does not claim an App
Store release or a permanent pricing commitment.

## Publish

GitHub Pages serves `main` from the repository root (`/`). `.nojekyll` keeps the
site static. Push a commit and wait for the Pages deployment to succeed; verify
the three public pages and asset responses before calling it published.

The icon PNGs are approved Little Pieces app artwork, copied without edits.
Privacy wording reflects the current app source and the hosting practices in
[GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).
No personal photo fixtures, app source, signing data, or API credentials belong
in this repository.
